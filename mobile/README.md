# mobile

Aplicativo mobile do Shogun — React Native.

Responsabilidades:
- captura de voz no celular (push-to-talk / wake word);
- interface de conversa;
- reprodução da resposta em voz;
- comunicação com o `server/` via WebSocket.

## Setup

Ainda não inicializado. Para criar o projeto:

```bash
npx create-expo-app@latest .
npm run start
```

Pré-requisitos: Node.js 20+ e Android Studio / Xcode conforme a plataforma alvo.
